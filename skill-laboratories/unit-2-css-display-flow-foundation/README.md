# Skill Lab 2.6 — CSS Display and Basic Layout Flow

## Purpose
Practice understanding block, inline, and inline-block display behavior.

## Skills Practiced
- Using `display: block`
- Using `display: inline`
- Using `display: inline-block`
- Understanding normal layout flow
- Comparing line behavior and box sizing

## Evidence
This lab is complete when:
- Block elements appear on separate lines
- Inline elements appear on the same line
- Inline-block elements stay inline while accepting width and height
- I can explain the difference between the three display types
