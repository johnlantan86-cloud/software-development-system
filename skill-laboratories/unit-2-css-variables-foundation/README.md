# Skill Lab 2.15 — CSS Variables Foundation

## Purpose
Practice defining reusable CSS values and applying them with custom properties.

## Skills Practiced
- Using `:root`
- Creating custom properties with `--name`
- Using `var()`
- Reusing colors and spacing values
- Understanding how variables improve consistency and maintenance

## Evidence
This lab is complete when:
- I can explain what a CSS variable is
- I can explain what `:root` is used for
- I can explain what `var()` does
- I can reuse one variable in multiple CSS rules
- I can explain why variables make styles easier to maintain
