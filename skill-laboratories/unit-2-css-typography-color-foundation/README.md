# Skill Lab 2.7 — CSS Typography and Color Foundation

## Purpose
Practice controlling text appearance and basic colors with CSS.

## Skills Practiced
- Using `font-family`
- Using `font-size`
- Using `font-weight`
- Using `line-height`
- Using `text-align`
- Using `color`
- Using `background-color`

## Evidence
This lab is complete when:
- I can explain what font size controls
- I can explain what font weight controls
- I can explain what line height controls
- I can distinguish text color from background color
- I can explain what text alignment does
