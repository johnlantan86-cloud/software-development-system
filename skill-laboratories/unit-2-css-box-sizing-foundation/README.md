# Skill Lab 2.4 — CSS Box Sizing and Predictable Widths

## Purpose
Practice understanding the difference between content-box and border-box.

## Skills Practiced
- Using `box-sizing`
- Understanding default `content-box`
- Understanding `border-box`
- Predicting total visible width
- Comparing box sizes

## Evidence
This lab is complete when:
- I can explain why content-box becomes wider than the declared width
- I can explain why border-box stays within the declared width
- I can compare the two behaviors in the browsere
