# Skill Lab 2.5 — CSS Units Foundation

## Purpose
Practice understanding fixed and relative CSS units.

## Skills Practiced
- Using `px`
- Using `%`
- Using `rem`
- Using `vh`
- Using `vw`
- Understanding parent-relative and viewport-relative sizing

## Evidence
This lab is complete when:
- I can explain what `px` means
- I can explain what `%` depends on
- I can explain what `rem` depends on
- I can explain what `vh` and `vw` depend on
- I can predict relative sizes correctly
