# Skill Lab 1.6 — HTML Forms Foundation

## Purpose
Practice creating a basic HTML form.

## Skills Practiced
- Using `<form>`
- Using `<label>`
- Connecting labels to inputs with `for` and `id`
- Using `<input>`
- Using `<textarea>`
- Using a submit button
- Using `required`

## Evidence
This lab is complete when:
- The page has a form
- Each input has a connected label
- The form has a name field
- The form has an email field
- The form has a message field
- The form has a submit button
- I can explain what `required` does
