# Skill Lab 2.10 — CSS Flexbox Foundation

## Purpose
Practice arranging elements with CSS Flexbox.

## Skills Practiced
- Using `display: flex`
- Using `flex-direction`
- Using `justify-content`
- Using `align-items`
- Using `gap`
- Understanding the main axis
- Understanding the cross axis

## Evidence
This lab is complete when:
- I can explain what `display: flex` does
- I can explain the difference between row and column
- I can identify the main axis and cross axis
- I can explain what `justify-content` controls
- I can explain what `align-items` controls
- I can explain what `gap` does
