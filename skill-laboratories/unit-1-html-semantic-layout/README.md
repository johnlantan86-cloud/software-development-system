# Skill Lab 1.5 — HTML Page Sections and Semantic Layout

## Purpose
Practice organizing a full web page using semantic HTML layout tags.

## Skills Practiced
- Using `<header>`
- Using `<nav>`
- Using `<main>`
- Using `<section>`
- Using `<footer>`

## Evidence
This lab is complete when:
- The page has a header area
- The page has navigation links
- The page has one main content area
- The page has multiple sections
- The page has a footer
- I can explain why semantic tags are better than using only generic containers
