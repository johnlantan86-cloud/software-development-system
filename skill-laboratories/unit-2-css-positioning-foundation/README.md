# Skill Lab 2.9 — CSS Positioning Foundation

## Purpose
Practice understanding static, relative, and absolute CSS positioning.

## Skills Practiced
- Using `position: static`
- Using `position: relative`
- Using `position: absolute`
- Using `top`, `right`, `bottom`, and `left`
- Understanding normal document flow
- Understanding positioned ancestors

## Evidence
This lab is complete when:
- I can explain static positioning
- I can explain how relative positioning affects normal flow
- I can explain how absolute positioning affects normal flow
- I can explain what an absolutely positioned element uses as its positioning reference
