# Skill Lab 2.3 — CSS Box Model Foundation

## Purpose
Practice understanding and controlling the CSS box model.

## Skills Practiced
- Using `width`
- Using `padding`
- Using `border`
- Using `margin`
- Understanding content width versus total visible box size

## Evidence
This lab is complete when:
- The page has visible box model examples
- I can explain content, padding, border, and margin
- I can explain why a 300px content width can create a box wider than 300px
