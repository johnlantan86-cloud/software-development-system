# Skill Lab 2.1 — Connecting CSS to HTML

## Purpose
Practice connecting an external CSS file to an HTML file.

## Skills Practiced
- Creating a CSS file
- Connecting CSS with `<link>`
- Using `rel="stylesheet"`
- Using `href` as the CSS file path
- Verifying that CSS changes appear in the browser

## Evidence
This lab is complete when:
- The HTML file links to `style.css`
- The CSS file changes the page appearance
- I can explain what `<link rel="stylesheet" href="style.css">` does
