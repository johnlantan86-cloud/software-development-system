# Skill Lab 2.2 — CSS Selectors Foundation

## Purpose
Practice using CSS selectors to target HTML elements.

## Skills Practiced
- Using element selectors
- Using class selectors
- Using ID selectors
- Connecting selectors to HTML attributes
- Understanding when to use class versus ID

## Evidence
This lab is complete when:
- Element selectors style HTML tags
- Class selectors style elements with class names
- ID selectors style specific elements
- I can explain the difference between element, class, and ID selectors
