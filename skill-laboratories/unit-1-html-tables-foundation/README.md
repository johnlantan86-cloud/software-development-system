# Skill Lab 1.7 — HTML Tables Foundation

## Purpose
Practice creating a simple HTML table.

## Skills Practiced
- Using `<table>`
- Using `<thead>`
- Using `<tbody>`
- Using `<tr>`
- Using `<th>`
- Using `<td>`

## Evidence
This lab is complete when:
- The page has a table
- The table has a header area
- The table has a body area
- The table has rows
- The table has header cells
- The table has data cells
- I can explain when tables should be used
