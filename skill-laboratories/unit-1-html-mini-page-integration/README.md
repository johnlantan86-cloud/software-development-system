# Skill Lab 1.8 — HTML Mini Page Build Integration

## Purpose
Build one complete mini HTML page using all Unit 1 skills learned so far.

## Skills Integrated
- HTML document structure
- Headings and paragraphs
- Navigation links
- Semantic layout
- Images and file paths
- Lists
- Tables
- Forms
- Footer content

## Evidence
This lab is complete when:
- The page has valid HTML structure
- The page has header, nav, main, sections, and footer
- The page has an image with a working file path
- The page has a list
- The page has a table
- The page has a form
- I can explain how these pieces work together in one page
