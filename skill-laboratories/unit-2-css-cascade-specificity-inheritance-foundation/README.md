# Skill Lab 2.8 — CSS Cascade, Specificity, and Inheritance Foundation

## Purpose
Practice understanding how CSS decides which styles apply when multiple rules affect an element.

## Skills Practiced
- Understanding inheritance
- Comparing element, class, and ID specificity
- Understanding source order
- Recognizing when a direct rule overrides an inherited value

## Evidence
This lab is complete when:
- I can explain inheritance
- I can explain why a direct rule beats an inherited value
- I can rank element, class, and ID selectors by specificity
- I can explain why a later rule wins when specificity is equal
