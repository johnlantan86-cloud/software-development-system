# Skill Lab 1.4 — HTML Images and File Paths

## Purpose
Practice using images in HTML and connecting files with correct paths.

## Skills Practiced
- Using the `<img>` tag
- Using the `src` attribute
- Using the `alt` attribute
- Understanding same-folder and child-folder paths

## Evidence
This lab is complete when:
- The page has an image tag
- The image path uses the `images` folder
- I can explain what `src` does
- I can explain what `alt` does
- I can explain why folder names must match exactly
