# Skill Lab 1.3 — HTML Links and Navigation

## Purpose
Practice creating links and basic page navigation.

## Skills Practiced
- Creating links with `<a>`
- Using the `href` attribute
- Linking to sections with IDs
- Creating basic navigation with `<nav>`
- Linking to external websites

## Evidence
This lab is complete when:
- The page has a `nav` section
- The page has links using `<a>`
- I can explain what `href` does
- I can explain the difference between `#section`, `page.html`, and `https://...`
