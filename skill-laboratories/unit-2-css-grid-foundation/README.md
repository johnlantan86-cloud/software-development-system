# Skill Lab 2.11 — CSS Grid Foundation

## Purpose
Practice creating two-dimensional layouts with CSS Grid.

## Skills Practiced
- Using `display: grid`
- Using `grid-template-columns`
- Using `fr`
- Using `gap`
- Understanding rows and columns
- Comparing Grid with Flexbox

## Evidence
This lab is complete when:
- I can explain what `display: grid` does
- I can explain what `fr` means
- I can predict how fractional columns divide space
- I can explain how rows are created
- I can explain what `gap` does
- I can explain why Grid is two-dimensional
