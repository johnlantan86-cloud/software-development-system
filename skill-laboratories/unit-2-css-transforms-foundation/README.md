# Skill Lab 2.14 — CSS Transforms Foundation

## Purpose
Practice visually moving, resizing, and rotating elements with CSS transforms.

## Skills Practiced
- Using `translateX()`
- Using `scale()`
- Using `rotate()`
- Understanding positive and negative transform values
- Understanding that transforms affect visual appearance without changing normal layout flow

## Evidence
This lab is complete when:
- I can explain what `translateX()` does
- I can explain what `scale()` does
- I can explain what `rotate()` does
- I can explain what positive and negative values mean
- I can verify transform behavior in the browser
