# Skill Lab 2.16 — CSS Mini Page Integration

## Purpose
Combine the major CSS foundations into one complete responsive mini page.

## Skills Integrated
- CSS selectors
- CSS variables
- Box model and spacing
- Typography and colors
- Flexbox
- Grid
- Media queries
- Pseudo-classes
- Transitions
- Transforms
- Responsive design

## Evidence
This lab is complete when:
- I can build the HTML structure with less guidance
- I can use Flexbox for navigation layout
- I can use Grid for a card layout
- I can make the Grid responsive with a media query
- I can use descendant selectors such as `.nav-links a`
- I can use `:hover` on specific elements
- I can match transitions to the properties that actually change
- I can reuse values with CSS variables
- I can verify the page in the browser at wide and narrow sizes

## Recovery Notes
During this lab I repaired:
- How descendant selectors work
- How `.nav-links a:hover` targets links inside a navigation container
- Why a transition must name the property that changes
