# Skill Lab 2.12 — CSS Responsive Media Queries Foundation

## Purpose
Practice making layouts adapt to different viewport widths.

## Skills Practiced
- Using media queries
- Using `max-width`
- Changing Grid layout at a breakpoint
- Understanding responsive design
- Testing layouts at different viewport sizes

## Evidence
This lab is complete when:
- I can explain what a media query is
- I can explain what `max-width: 700px` means
- I can explain why the grid changes from 3 columns to 1 column
- I can verify the layout at wide and narrow viewport sizes
