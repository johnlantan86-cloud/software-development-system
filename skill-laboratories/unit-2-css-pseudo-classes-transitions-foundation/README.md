# Skill Lab 2.13 — CSS Pseudo-classes and Transitions Foundation

## Purpose
Practice styling elements based on user interaction and making visual changes smoother.

## Skills Practiced
- Using `:hover`
- Using `:focus`
- Using `transition`
- Understanding interaction states
- Testing hover and focus behavior in the browser

## Evidence
This lab is complete when:
- I can explain what `:hover` does
- I can explain what `:focus` does
- I can explain what `transition` does
- I can verify hover behavior in the browser
- I can verify focus behavior in the browser
